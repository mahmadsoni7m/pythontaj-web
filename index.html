Барнома бехатар аст?

Ҳа. Файли APK бевосита дар ҳамин сайт ҷойгир аст. Барнома иҷозати интернетро танҳо барои навсозии дарсҳо истифода мебарад ва маълумоти шахсиро ҷамъ намекунад.

Бе интернет кор мекунад?

Ҳа. Ҳамаи дарсҳо ва Python дар дохили барнома мебошанд. Интернет танҳо барои навсозии дарсҳо лозим аст.

Код барои дарсҳои пулакӣ чӣ тавр кор мекунад?

Барнома ID-и телефони шуморо нишон медиҳад. Онро ба мо мефиристед ва код мегиред. Код танҳо ба телефони шумо мувофиқ аст ва бе интернет дарсҳоро мекушояд.

Агар телефонамро иваз кунам?

Бо мо тавассути WhatsApp ё Telegram тамос гиред ва ID-и телефони навро фиристед.

Навсозиро чӣ тавр мегирам?

Дарсҳои нав худкор меоянд. Версияи нави барнома дар ҳамин сайт мебарояд: файли навро боргирӣ кунед ва болои кӯҳна насб намоед, маълумоти шумо гум намешавад.
