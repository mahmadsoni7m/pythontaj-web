# PythonТаҷ - вебсайти боргирӣ

Сайти ҷамъиятӣ барои боргирии барномаи Android. Ҳеҷ сервер ва Releases лозим нест.

## APK-ро гузоштан
1. Файли APK-ро бо номи **PythonTaj.apk** (лотинӣ) ба ҳамин репозитория гузоред (дар папкаи асосӣ, дар паҳлӯи `index.html`).
   - Дар браузер: Add file → Upload files (то 25 МБ). Агар калонтар бошад, аз Termux: `git add PythonTaj.apk && git commit -m apk && git push`.
2. Settings → Pages → *Deploy from a branch* → `main` / `(root)`.
3. Версияи нав: файлро бо ҳамон ном иваз кунед. Рақами версия: `js/site.js` → `CFG.VERSION`.

Тамос, нарх: `js/site.js` (`CFG`).
